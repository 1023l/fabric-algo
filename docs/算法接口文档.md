# fabric-algo · 算法接口文档（第三方软件版）

> 给别的软件团队看的：**怎么调用我们的算法、输入什么、输出什么**。
> 算法实现：`c:\projects\fabric-algo`，启动入口 `python web_server.py`（默认端口 8001）。

## 一句话总结

算法就是一个 pipeline：**输入一张图片（视频的每一帧），输出一个 JSON**，JSON 里就是界面显示的那几个字段——正向、反向、累计、L/R、成双、单只、鞋码。

第三方软件只需调用 **1 个接口**：`POST /api/algo/process`。每来一帧调一次，所有累计算法（跟踪、过线计数、去重、识别）都在服务端自动完成。

---

## 主接口：POST /api/algo/process

```
POST http://<服务器IP>:8001/api/algo/process
Content-Type: application/json
```

### 请求（入参）

```json
{
  "session_id": "cam_01",
  "image_b64": "/9j/4AAQSkZJRgA...（一帧图像的 base64）",
  "line_ratio": 0.5
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `session_id` | 是 | 同一条视频流所有帧用同一个字符串；换视频/清零就换一个新的 |
| 图像 | 是 | 四选一：`image_b64`（base64）/ `image_url`（http 图片地址）/ `image_path`（服务器本地路径）/ 或 multipart 上传 `image` 文件 |
| `line_ratio` | 否 | 计数线位置，0~1（0.5=画面正中），默认 0.5 |
| `ocr` | 否 | 默认 true（识别 L/R 和鞋码）；纯计数可传 false 更快 |
| `fabric_conf` | 否 | 布片检测置信度，默认 0.4 |
| `rec_thresh` | 否 | 文字识别置信度，默认 0.35 |

### 响应（出参）

```json
{
  "ok": true,
  "elapsed_ms": 35,
  "data": {
    "session_id": "cam_01",
    "image_shape": [1080, 1920],
    "summary": {
      "正向前": 16,
      "反向前": 0,
      "累计": 16,
      "L": 8,
      "R": 8,
      "成双": 8,
      "单只": 0,
      "鞋码": {"30": 16},
      "计数线位置": 0.5
    },
    "pieces": [
      {
        "track_id": 12,
        "piece_box": [542, 344, 1109, 1080],
        "side": "above",
        "crossed": false,
        "text": "30-30TR",
        "shoe_size": 30,
        "lr_flag": "R"
      }
    ]
  }
}
```

### 字段含义

**summary 就是界面显示的那排数字：**

| 字段 | 含义 |
|---|---|
| 正向前 | 累计正向过线（穿过去）的鞋布片数 |
| 反向前 | 反向过线（退回来）的片数 |
| 累计 | 正向前 - 反向前 = 最终已检鞋片数 |
| L / R | 其中识别为左脚 / 右脚的只数 |
| 成双 | L 和 R 配成对的双数 = min(L, R) |
| 单只 | 落单的只数 = |L - R| |
| 鞋码 | {"30": 16} = 尺码 30 的 16 只 |
| 计数线位置 | 当前计数线高度（0~1） |

**pieces 是这一帧每块布片的明细**（每块布一行）：位置、是否刚过线、识别到的文字、鞋码、L/R。软件不需要明细的话忽略它，只看 summary 即可。

### 示例代码（Python）

```python
import base64, cv2, requests

cap = cv2.VideoCapture("c:/x/video.mp4")
sid = "cam_01"
while True:
    ok, frame = cap.read()
    if not ok: break
    _, jpg = cv2.imencode(".jpg", frame)
    r = requests.post("http://127.0.0.1:8001/api/algo/process", timeout=5, json={
        "session_id": sid,
        "image_b64": base64.b64encode(jpg.tobytes()).decode(),
        "line_ratio": 0.55,
    }).json()
    s = r["data"]["summary"]
    print(s["累计"], "L:", s["L"], "R:", s["R"], "鞋码:", s["鞋码"])
requests.delete(f"http://127.0.0.1:8001/api/algo/count_sessions/{sid}")  # 视频结束，清零
```

### 示例代码（curl）

```bash
# 用本地图片路径
curl -X POST http://127.0.0.1:8001/api/algo/process \
  -H "Content-Type: application/json" \
  -d '{"session_id":"cam_01","image_path":"C:/data/frame_50.jpg"}'
```

### 常见问题

- **没有 session_id 会怎样**：报 400 错误（必须传）。
- **清零/换视频**：换一个新的 session_id 即可；也可以调 `DELETE /api/algo/count_sessions/{sid}` 显式清零。
- **性能**：RTX 4060 上每帧约 30~45ms（含识别）；纯计数（ocr=false）约 8ms。
- **中文路径**：`image_path` 支持中文路径（服务端已做安全处理）；更推荐直接传 base64 或 URL，不碰文件系统。
- **传图方式**：除了 JSON 里的 base64，也可以 multipart 上传 `image` 文件字段，最省心。

## 底层接口（一般用不到，供联调/调试）

以下接口是 pipeline 拆开的原子步骤，软件集成**不需要**用它们，只有调试模型效果时有用：

| 接口 | 干什么 | 输入 | 输出 |
|---|---|---|---|
| `POST /api/algo/fabric` | 只检测布片框 | 图片 | `boxes:[{box,cls,conf}]` |
| `POST /api/algo/text` | 只检测文字区域（横/竖） | 图片 | `boxes:[{box,cls_name,conf}]` |
| `POST /api/algo/ocr` | 识别一张裁剪好的文字小图 | 图片 | `{text,score,shoe_size,lr_flag}` |
| `POST /api/algo/pieces_ocr` | 单帧：每块布的完整识别 | 图片 + ocr | `pieces:[{piece_box,text,shoe_size,lr_flag}]` |
| `POST /api/algo/count_frame` | 主接口的底层版（字段是英文） | 同 process | `{stats,pieces}` |

（`/fabric`、`/text`、`/ocr`、`/pieces_ocr`、`/count_frame` 都支持加 `/json` 后缀走 JSON body，传图方式和主接口一样四选一。Swagger 文档在 `http://IP:8001/docs`，所有接口自动列出、可在线试。）

## 启动与部署

```bash
cd C:\projects\fabric-algo
python web_server.py --host 0.0.0.0 --port 8001
```

- 健康检查：`GET http://IP:8001/health` → `{"status":"ok"}`
- 接口文档：`GET http://IP:8001/docs`（Swagger，可直接点"Try it out"测试）
- 模型版本：默认加载 `models/fabric/fabric20260828V2.engine`、`models/text/text20260831V1.engine`、`models/rec/rec20260828V3.engine`（都是最新 TRT 引擎）。换模型改 `algo_routes.py` 顶部常量即可，软件方不用改。

### 推荐部署方式

算法服务和软件各自独立部署，互不影响：

```cmd
start python web_server.py --port 8001    # 演示页面（如有需要）
start python web_server.py --port 8002    # 算法专用：软件只调 8002 的 /api/algo/*
```

### 错误码

| HTTP | 含义 |
|---|---|
| 400 | 参数错（没传 session_id / 图像读不到等） |
| 422 | JSON 字段类型错 |
| 500 | 服务端异常（看日志） |
| 504 | 单次调用超 8 秒（一般是图片 URL 下载太慢） |
